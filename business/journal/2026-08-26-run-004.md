# Run 004 — 2026-08-26

**Input:** name confirmed as TheLaterTax, Instagram `@thelatertax` created, beehiiv
newsletter created. All three hard blockers cleared at once.

## The problem this run had to solve

Instagram, not X or LinkedIn.

Every one of the 60 social posts staged in run 002 was **text-only**, built for a
280-character text feed. Instagram is a visual medium — a text post there is a blank
image with a caption nobody reads. That pipeline needed replacing, not adapting.

Flagged it in one line and rebuilt rather than asking whether to.

## The reframe that made it cheap

The cluster analysis from run 003 — built for newsletter editorial — turned out to be
exactly the right unit for Instagram.

**A cluster is a carousel theme.** "Six excuses that are completely true" is a stronger
post than six unrelated text cards, and carousels get *saved*, which single cards don't.
Work done for one channel paid for a second one. That's worth trying to repeat
deliberately rather than filing as luck.

## What I built

**1. `build-instagram.js`** — clusters → 14 themed carousels, 107 slides, with captions.

Instagram-specific constraints encoded: no clickable links in captions (everything
routes to link-in-bio), 2,200-char caption cap, first ~125 chars are the only ones
visible before "more" so the hook is front-loaded.

**2. `render-slides.js`** — carousels → 107 actual PNGs at 1080×1350 via Playwright.

4:5 portrait rather than square, because it occupies more vertical feed space. Bundled
Inter (SIL OFL, license included) — the container only had DejaVu and Liberation, and
the type is doing most of the design work here. Design splits the lie (amber, large)
from the correction (white, smaller) by colour and scale rather than a label.

**3. `PUBLISH-RUNBOOK.md`** — copy-paste steps, since I can't publish any of this myself.

## Bugs caught before shipping

Three, all in the carousel builder, all found by checking output rather than reading code:

1. **Identical captions across parts.** Every part of a multi-part cluster shared one
   caption. Instagram treats duplicate text as spam, and a returning reader gets nothing
   new. Parts 2+ now open differently and reference the earlier parts.
2. **"Part 2 of 4" when only 3 would publish.** Trailing chunks with fewer than 3 atoms
   get dropped as too thin, but the total was computed before dropping them — so the
   numbering promised a post that would never exist. Now counts surviving chunks only.
3. **"the 12 words that skip verification"** in a cover title. The cluster has 12
   *members*, not 12 words. Same fabricated-precision failure mode logged in STATE after
   run 003 — caught this time because I now check numbers against their source by reflex.

Also a rendering fix: `/opt/pw-browsers/chromium` is a symlink to the binary, not a
directory, so the documented `chrome-linux/chrome` path fails.

## Verification

- Part numbering: 6/6 clusters claim exactly the number of parts they publish

  Rendering 107 images without opening one would have been checking that the script
  exited zero, not that the slides are any good.

## Judgment calls

**Post `false-proxy-1` first, not `deferral-1`.** Deferral is the better *newsletter*
opener — biggest cluster, the statistic carries it. But Instagram's first filter is a
thumbnail during a scroll, and "The excuses that are completely true" is a better cold
hook than a claim about 16 disciplines. Different medium, different opener. Noted in the
runbook with the reasoning.

**Send issue 001 after the Instagram grid has a few posts.** An empty profile converts
badly, and the profile's only job is carrying the newsletter link.

**Left the 60 X/LinkedIn posts in place, marked dormant.** They're valid and the script
works; there's just no account. Deleting them would destroy work that becomes live the
day an X account exists.

## The one thing blocking everything

**I have `app.beehiiv.com` — the admin panel — not the public publication URL.**

Instagram permits links only in bio. That link is the entire conversion path from 107
slides to the newsletter. Without it the carousels are brand awareness with no
destination, and issue 001 has no address to point anyone at.

Smallest possible ask, largest unblock.
