# Run 002 — 2026-08-25

**Starting state:** run 001 shipped the content engine and blocked on channel
selection. Both blocking decisions came back this run.

## Decisions received

1. **Channel: newsletter + one social.** The recommendation was taken.
2. **Byline: brand / publication name.** Editorial voice, no personhood claim.

## What I did

**1. Refused to block on the name.**
The byline decision implies the publication needs a name, which nobody has picked. I
did not stop and ask. Every generated artifact reads a single `BRAND` token from
`business/brand.json`, currently set to the working name `The Later Tax`. Choosing a
real name is a one-line edit plus a re-run. Three candidates written up in
`inbox/2026-08-25-decisions.md` with my pick and the argument against it.

**2. Built the social formatter** (`scripts/format-social.js`).
Turns atoms into platform-ready post text in two formats — X (hard 280-char budget)
and LinkedIn (longer, eng-leader framing). Emitted in calendar order so the queue
lines up with the schedule. Result: **60 posts, all 60 under the X limit**, longest
190 chars.

Generating both formats was deliberate. The social platform is still unpicked, and
producing both costs almost nothing while removing the decision from the critical path.

**3. Converted issue 001 to editorial voice.**
First-person singular throughout the draft, which contradicts a brand byline. Patched.
The one remaining "I" is inside a quoted rationalization — correct to leave, it's an
engineer's words, not the publication's.

**4. Wrote landing page copy** (`content/drafts/landing-page-copy.md`).
Platform-agnostic markdown rather than HTML, since the platform doesn't exist yet.
Headline leads with the finding, not the publication — nobody cares about a new
newsletter, they care that their deferral backlog is untracked.

## Verification

- Formatter output: 60/60 within the X character budget, 0 malformed quote handling
- Issue 001: swept for first-person singular after the voice patch; one hit, correctly
  a quotation
- Pipeline re-run clean from scratch (see below)

Two bugs caught in the formatter before it ran: a stray combining character that had
gotten into the heredoc, and a quote-stripping regex with duplicated `"` characters
where the curly quotes belonged. The second would not have crashed — it would have
silently failed to strip typographic quotes, leaving malformed post text. Fixed both
and verified with a syntax check plus an explicit malformed-output count.

## Judgment call worth recording

The landing page has a social proof block. I left it **empty and explicitly marked
do-not-publish** rather than writing "join 1,000+ engineers."

There are zero subscribers. A fabricated number is the single fastest way to lose an
audience built on the promise that we show our work — and the whole positioning of this
publication is evidence over opinion. An empty section is a weaker page this month and
a publication that still exists next year.

Same reasoning as the fabricated statistic caught in run 001. That's twice now that the
tempting move was inventing a number. Worth naming as a standing failure mode rather
than treating each instance as a one-off.

## What I did not do

- **Did not create accounts.** Newsletter platform or social — human action.
- **Did not publish anything.** 60 posts, one issue, and a landing page are staged.
- **Did not pick the social platform.** Both formats generated; decision deferred at
  near-zero cost.
- **Did not build monetization.** Audience is still 0.
